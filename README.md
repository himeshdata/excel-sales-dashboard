📊 Sales Performance Analysis Dashboard
I recently created a Sales Performance Dashboard using Microsoft Excel as part of my Data Analytics learning journey.
Key features of this dashboard:
✅ Top 5 Sales Executives based on sales performance.
✅ Bottom 5 Sales Executives to identify improvement areas.
✅ Top 5 performers based on Target Hit %.
✅ Bottom 5 performers based on Away From Target %.
✅ Employee-wise sales performance analysis.
✅ Interactive visualizations using Excel charts and Pivot Tables.
